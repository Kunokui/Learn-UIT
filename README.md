# Learn-UIT

Kho lưu các file HTML (artifact) để ôn tập các môn học tại UIT.

## Cách dùng

- Bỏ file `.html` vào repo (có thể chia thư mục theo môn, ví dụ `CTDL/`, `OOP/`...).
- Commit và push:

```bash
git add .
git commit -m "Thêm bài ôn tập"
git push
```

- Xem online qua GitHub Pages: https://kunokui.github.io/Learn-UIT/
  Trang chủ tự liệt kê mọi file `.html` trong repo.
